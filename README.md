# Discipline Tracker

Android приложение, написанное на Unity, для отслеживания правильных привычек. 
Ежедневное выполнение активностей формирует стабильность.
Внесение данных позволяет увидеть картину стабильности на протяжении большого периода времени.

Цель - развивать самодисциплину, мотивируясь статистикой и прогрессом.
Изначально проект задумывался как инструмент для спорта, но в итоге это не про спорт, а про стабильность и
развитие желаемых привычек.

Данный проект не завершён, но приложение работает и есть люди, кто им регулярно пользуется.
Разработка в данный момент не ведётся, однако есть шанс, что в будущем закрою проект, переписав его на java.
